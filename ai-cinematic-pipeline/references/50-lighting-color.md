# 50 · 光影色彩身份制（Lighting & Color Identity）

> 这是视听方法的**核心灵魂**。光不是照明，而是叙事：颜色分阵营、走位穿光区、反差随情绪。新项目先用本方法建立自己的色彩身份表，再开拍。

## 1. 总原则

- 每种力量、每个阵营绑定固定光色，观众无需台词即可感知关系。
- 每个镜头必须能回答：**主光从哪来、什么色、是软是硬？哪里被照亮、哪里沉入阴影？**
- 光只在需要处点亮；事件光局部出现，绝不为“好看”而全屋照亮。
- 视频提示词里灯光是优先级锁定项（写法见 `42` 第 2 节）；图像提示词里写具体光照参数（主光、光比、衰减，见 `10` 第 3 节）。

## 2. 如何为新项目建立色彩身份表

为每个阵营/关键空间/关键事件指定一个固定色，并写明：归属、典型出现物、情绪含义、硬性使用规则。建表示例：

| 色彩 | 归属 | 出现物 | 情绪/含义 | 硬规则 |
|---|---|---|---|---|
| （例）银蓝 | 超自然/神性 | 神血、图腾、崩解碎片 | 超凡、超越凡人 | 不用于凡人/普通反光 |
| （例）冷白冷灰 | 主角、真相、孤立 | 高窗日光、清晨冷区 | 清醒、疏离、被排斥 | — |
| （例）暖橙暖金 | 权力场、虚伪温情 | 门光、壁灯、壁炉、吊灯 | 财富、掌控、表面温暖 | — |
| （例）橙金火焰 | 背叛与贪欲 | 事件火，只从下方局部照亮 | 危险、贪婪、刺杀 | 戏终可收 |
| （例）电视冷蓝 | 现代预言/新闻事件 | 屏幕光、突发新闻 | 应验、外部冲击 | 只染局部 |
| （例）铁锈工业灰 | 粗粝生产空间 | 锈钢、龙门吊、工具 | 破败、力量、待重生 | — |

方法要点：特殊色（如神性色、血液色）必须写清**专属边界**，并在负面限制里阻断其被滥用（例：“神血为银蓝，禁普通红色神血”）；会发光的标志物规定“一闪即灭”，不持续发光。

## 3. 光源类型与事件光

- 主光：决定造型与方向（高窗日光、落地窗晨光、顶部天光）。
- 辅光：填充暗部（云层反射、环境反弹、弱暖灯）。
- 边缘光/轮廓光：从肩后、发缘勾出人物轮廓，使其与背景分离。
- 事件光：随剧情临时出现（火焰、电视屏幕光、壁炉），范围局部、方向明确，戏终可收。

## 4. 执行细则

1. **锚定方向**：每镜写明光从哪一侧来（右后方窗光、左侧高窗、落地窗方向）。
2. **光轴连续**：同一场戏跨镜头，光源方向保持一致，不无故移动。
3. **近侧受光、远侧留影**：近侧脸被照亮，远侧脸沉入浅影，塑造立体。
4. **阴影切割**：用柱影、栏杆影、窗框影切过面孔或身体，表现被压制/被分隔。
5. **边缘光**：肩后/发缘给一道轮廓光，把主体从背景提出。
6. **眼神光（自然）**：可写“目光、视线、眼里映出窗形/火光的倒影”，但**不写眼睛发光、点亮瞳孔**（见第 8 节）。
7. **反差随情绪**：私密/温情低反差；刺杀、崩解、败露强对比；平静陈述用柔和中间调。
8. **事件光局部**：火焰只照亮相接处与下半张脸；电视光只染侧面；不让事件光吞掉整个空间。
9. **光随动作**：人物转身、靠近、退后时，光在脸上的位置随之改变并保持合理。

## 5. 走位即穿越光区

- 人物在空间里移动，就是在冷暖、明暗阵营之间移动：由冷窗区走进暖色权力场（进入中心）；从暖灯区踏入窗光（被真相照亮、态度暴露）。
- 用“他此刻站在哪片光里”外化立场转变；同框两人若分处冷暖两区，关系对立一目了然。
- 情绪距离与镜头方向绑定（靠近=前推并入同一光区，疏远=后撤分处两区，见 `27` 第 7 节）。

## 6. 时间与天气如何决定光

- **早晨九点（低太阳）**：暖金色、低斜、柔和，光斑边缘柔化、反差低、阴影长而软；适合温情、私密、从容或暗涌。
- **正午 / 高太阳**：偏白、偏硬，光斑边缘锐利、反差高；用户若明确“不要那么白硬”，即使参考图偏白硬，也改按柔和暖光处理。
- **日外开阔地**：可接受更明亮、稍硬的自然光，表现粗粝与力量。
- **夜内**：以暖色灯/壁炉为主光，暗部占比大，轮廓光分离人物。
- 云层、晨雾、薄纱窗帘可作天然柔化与反弹。

## 7. 不同空间的光线配方（按功能套用）

- 破败私密空间（阁楼/旧屋）：单侧老窗冷灰光，低反差，浮尘，暗部占多。
- 超现实/神圣空间：顶部明亮天光 + 关键道具反光，浅色材质，秩序感。
- 权力客厅：高窗冷白光与壁炉/台灯暖橙并存，人物按阵营分光区。
- 生活空间（卧室/厨房/餐桌）：东向暖晨光，柔和有情。
- 工作空间（书房/谈判桌）：北向中性日光、台灯局部光，清晰有理。
- 晚会/夜场：暖金主光、暗背景，人物被轮廓光分离。
- 私密娱乐室（台球室/酒吧）：低斜暖金晨光或暖暗灯光，桌面柔光斑，深处暖暗，整体低反差。
- 工业厂区：日外明亮自然光 + 铁锈环境色，开阔、硬朗。

## 8. 易误导 AI 的光影描绘：禁用与替换

以下写法可能让模型生成异常高亮、变色、特效，**正面提示词一律不写**：

| 禁用写法 | 替换为（真实、动作性） |
|---|---|
| 眼睛发光 / 眼里燃起光 / 点亮眼睛 | 目光锐利 / 眼神笃定 / 视线锁定 |
| 点亮瞳孔 / 瞳孔里有光（特效义） | 瞳孔收紧（生理反应）/ 视线移向 |
| 指节发白 / 关节发白 / 手指发白 | 手指收紧 / 握稳 / 手指收拢 |
| 满脸被魔法光照亮 | 晨光照亮近侧脸 |
| 皮肤泛着（非自然）光 | 皮肤质感真实、自然肤色 |
| 印记持续发光 / 越来越亮 | 印记一闪即灭 / 极短一闪后收敛 |

负面限制中的安全表述（用这些，不重复禁用原词）：
`禁眼部自发光、光束、异常高亮、特效反光；禁皮肤异常变色；禁印记常亮。`

> 金属、玻璃、酒液、水面的**真实物体反光**可正常描写；被限制的是人体/眼部的非自然发光与异常变色。

## 9. 光影自检

- [ ] 每镜明确光源方向、冷暖、软硬；跨镜光轴连续。
- [ ] 已按项目色彩身份表用色，特殊色未越界、血液/标志物规则在需要处出现。
- [ ] 近侧受光、远侧留影；必要处有轮廓光与阴影切割。
- [ ] 事件光局部、克制，未全屋照亮；反差与情绪匹配。
- [ ] 人物走位与光区转变一致，能外化立场。
- [ ] 时间点决定的光线软硬符合用户要求（如早晨九点柔和、不白硬）。
- [ ] 未出现“眼睛发光/指节发白”等易误导词；负面含“禁眼部自发光、异常高亮”。

## 10. 附：示例项目色彩身份表（仅演示绑定方法，勿照抄）

> 下表演示一套“重生/神性 + 豪门权力”题材如何绑定色彩。新项目应替换为自己的阵营与配色。

- **银蓝（silver-blue）= 神性专属**：神血、猫头鹰印记、崩解碎片、神力微光、瞳孔超现实反射。硬规则：神血必须银蓝、普通红血列入负面；银蓝不用于凡人/普通物体反光；猫头鹰印记只在特定瞬间“一闪即灭”。
- **冷白/冷灰 = 主角、真相、孤立**：高窗日光、老窗冷光、清晨冷区。
- **暖橙/暖金 = 家族权力场、虚伪温情**：门光、壁灯、壁炉、台灯、吊灯、吧台暖光。
- **橙金火焰 = 背叛与贪欲**：燃烧刀刃等事件火，只从下方局部照亮。
- **电视冷蓝 = 现代预言/新闻应验**：屏幕光、突发新闻，只染侧面。
- **绿色台呢 = 私密娱乐空间**：台球桌，纨绔、从容、私密。
- **铁锈/工业灰 = 造船厂等粗粝空间**：破败、力量、待重生。

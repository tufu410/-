# 51 · 视频负面限制总表（Negative Prompts Master List）

> 用于阻断 AI **视频**生成的常见崩坏。按镜挑相关项组合，不必每镜写全；句子可直接复制。图像模型不支持负面提示词，见文末说明与 `10` 第 3 节。

## 1. 使用方法

- 每镜从十类中挑与本镜真正相关的条目（3–7 条为宜），堆砌无关项稀释权重。
- 与正面提示词对应：正面要求什么，负面就阻断其反面崩坏。
- 人名、数量、道具状态写具体（“仅 A 与 B”“禁第三杯酒”），比泛泛“不要出错”有效。
- 默认优先行内局部锁定（紧贴对应正向规则写一句“禁止 XX”），而非末尾堆一大段（见 `43` 第 5 节）。

## 2. 十类负面清单

### ① 人数 / 角色
- `仅本场人物行指定的角色，不新增宾客/仆人/路人。`
- `单人镜，不出现第二人。`
- `禁人物复制、同一个人出现多次、分身。`
- `禁错误角色提前登场。`

### ② 畸形 / 穿模
- `禁多指、手指畸形、手指融合、多余肢体。`
- `禁五官错位、面部不对称崩坏、肢体穿模。`
- `禁手部比例错误、关节反向。`

### ③ 机位 / 构图
- `禁正面证件照式构图、正面脸部特写。`
- `禁镜头正对角色、怼脸。`
- `禁越轴、视线方向错乱。`

### ④ 表演 / 口型
- `禁张嘴说 VO、嘴唇配合内心独白。`
- `禁夸张惊叫、狂笑、嚎哭、表情过度。`
- `禁过度慢动作、动作拖沓、动作重复。`
- `禁口型与台词错乱。`

### ⑤ 特效 / 神力（按项目符号替换）
- `禁标志物/印记常亮、持续发光。`
- `禁眼部自发光、光束、异常高亮、特效反光。`
- `禁特效光吞掉全屋、光球常驻、提前变身。`
- `禁变身装束/特效凭空出现。`

### ⑥ 空间 / 光轴
- `禁空间结构偏离参考图、家具位置漂移。`
- `禁光源方向漂移、光轴错误、忽明忽暗。`
- `禁场景穿帮出现现代/无关物件。`

### ⑦ 道具 / 文字
- `禁字幕、水印、Logo、可读乱码文字。`
- `禁文件/屏幕/白板文字乱码、图表乱生。`
- `禁道具复制（多柄刀、多杯酒、多根杆）。`
- `禁道具自动翻页、自行移动、漂浮。`

### ⑧ 血液 / 伤害（配色按项目色彩身份替换）
- `特殊血液按项目指定色（示例：神血为银蓝），禁普通红色神血。`
- `禁血浆遮屏、伤口扩大、血腥裂伤、肢解。`
- `禁骨折外露、伤害夸张。`

### ⑨ 叙事 / 节奏
- `禁提前揭示反转、配角抢戏。`
- `禁角色提前做出后续动作（站起、拔刀、推人）。`
- `禁所有人动作整齐同步、同时站起。`

### ⑩ 版权 / 真实标识
- `新闻只写“某台风格”，禁真实台标/Logo 精确复制。`
- `禁真实品牌商标、明星肖像精确复刻。`

## 3. 易误导光影禁令（高优先）

- 正面提示词中**禁止出现**：眼睛发光、眼里燃起光、点亮眼睛/瞳孔、指节发白、关节发白、手指发白、满脸被魔法光照亮、印记越来越亮（完整替换表见 `50` 第 8 节）。
- 负面统一用安全表述（不重复禁用原词）：
  - `禁眼部自发光、光束、异常高亮、特效反光。`
  - `禁皮肤/手指异常变色、不自然泛白。`
  - `禁印记常亮、亮度异常增强。`
- 允许保留：金属、玻璃、酒液、水面的**真实物体反光**；自然窗形眼神倒影；瞳孔收紧等真实生理反应。

## 4. 导演反向锁定短句（行内用，源自 `43`）

`无重复人物、无多余路人、无失效标签、首帧不为空、视线方向不错误、人物不远离地标、无正面平光、无 CG 塑料光泽、无游戏引擎质感、无漂浮运动、无字幕；除非指定，无背景音乐。`

光学相关按需加：`镜头全程不漂移到其他焦段、无鱼眼气泡畸变、无圆形暗角`（视场锁定见 `41`）。
物理相关按需加：`无浮空身体、无瞬移、无橡胶质感 CG 运动、布料与发丝有自然延迟`（见 `42`）。

## 5. 按场景的负面组合示例

- 特写（眼/手）：`禁正面特写、多指畸形、眼部自发光或光束、张嘴、人物复制。`
- 双人关系：`禁第三人入镜、肢体穿模、手指多指、动作提前、口型错乱。`
- 群像：`禁人物复制、动作整齐同步、所有人同时站起、表情一致、镜头眩晕。`
- 奇幻/崩解：`禁错误颜色血液、血腥肢解、生成多个身体、粒子遮满全屏、场景坍塌。`
- 生活/温情：`禁夸张表情、过度慢动作、邪魅笑、人物悬空、道具自发光。`
- 电视/新闻：`禁真实台标精确复制、屏幕乱码、人物穿出屏幕、画面剧烈闪烁。`

## 6. 视频 vs 图像：负面写法差异

- **视频模型**（Seedance/即梦/可灵等）：支持负面提示词时，用本文件的负面清单与行内锁定。
- **图像模型**（Soul/Soul Cinema/NBP/Seedream/GPT Image）：**没有负面提示词参数**，不写“不要 XX”，改用正向描述（干净皮肤 `clean dry skin`、空旷 `empty deserted street`、无 logo `plain unbranded surface`）；编辑类允许移除指令但必须写明空缺填充内容。详见 `10-image-prompts.md` 第 3 节。
- 不要把视频负面清单整段搬进图像提示词，否则反而引入想规避的概念。

## 7. 自检

- [ ] 每镜负面条目与本镜内容相关，未堆砌无关项。
- [ ] 人数、畸形、机位、口型、特效、空间、道具、血液、叙事、版权相关风险已覆盖。
- [ ] 含“禁眼部自发光、光束、异常高亮”，未出现“眼睛发光/指节发白”等禁用词。
- [ ] 特殊血液/标志物/新闻台标等项目硬规则在需要处出现。
- [ ] 图像任务未误用视频负面清单，已改为正向描述。

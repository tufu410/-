## 1. 标准成品镜头长什么样

```text
镜34｜01:19.8-01:22.8｜持酒嗤笑侧脸近景｜轻带
【场景锚点】台球室·日晨，严格对齐参考图三：深色木墙、绿色台呢，暖暗柔和、低反差；早晨九点柔和暖光从落地窗方向斜入。
【视角锚点】摄影机位于角色斜前方（图三机位），另一角色只以肩背前景虚化，焦点在主体。
【AI视频提示词】他像听到个笑话，单侧嘴角上扬、嗤笑一声，端着酒杯、手上再无他物，把事情轻飘飘说成烂摊子；暖暗柔光勾勒他苍白优雅的脸，皮肤质感真实。
【负面限制】禁正面脸部特写、手上出现多余道具、放声大笑、表情凶狠、手指畸形。
角色（嗤笑、嘴角上扬｜语速放慢，关键词咬重）：That's what you're freaking out about? It's a disaster zone.
```

## 2. 字段逐项规范

### 镜号
- 格式 `镜N`，全片连续编号；多场景不重置。
- 如需标注特殊身份，写在景别位置（如“图三锚点”“集尾钩子”）。

### 时间码
- 格式 `HH:MM:SS-HH:MM:SS.s` 或短集用 `MM:SS.s-MM:SS.s`，全片统一一种。
- 精确到 0.1 秒；前一镜结束时间 = 后一镜开始时间。
- 单镜常见时长：特写/反应约 2.0–2.4 秒；近景/中景约 2.4–3.0 秒；全景/群像约 2.6–3.2 秒（详见 `25`）。

### 景别
- 从景别谱系选词（见 `23-shot-types-camera.md`）：极近特写 / 眼神特写 / 手部特写 / 道具特写 / 侧脸近景 / 侧前近景 / 中景 / 过肩中景 / 中全景 / 群像中景 / 大全景 / 顶视 / POV 主观。
- 景别名后可加功能说明（“伏笔”“转场”“图三锚点”）。

### 运镜方式
- 写“运动 + 落点”：如 `快速前冲后骤停`、`微距移焦后冷停`、`低机位缓慢环绕四分之一圈`、`顺手势轻推后停`。
- 落点与动作“同步停”：动作命中/完成时镜头停住，形成重音。
- 情绪绑定方向：靠近/亲密 = 前推、跟拍、并入同一光区；疏远/压迫 = 后撤、拉开距离、抬高。

### 【场景锚点】
固定四要素，按序写：
1. 地点·日/夜·内/外（是否对齐某张参考图要明写，如“严格对齐图三”）。
2. 布景与材质：木、石、金属、织物、颜色、新旧。
3. 光源方向：哪一侧、冷暖、软硬、主光/辅光/事件光（色彩身份见 `50`）。
4. 空气质感：浮尘、蒸汽、薄烟、云层反射、晨雾。

### 【视角锚点】
- 摄影机的**物理坐标**：方位 + 高度 + 与人物关系（“床尾左前方腰高”“栏杆外侧低位”“越过 A 肩侧”）。
- 朝向：拍谁、前景/后景分别是什么。
- 强制交代前景遮挡物（肩、门板、柱、栏杆）与焦点落点。
- 转英文成品时，此处对应机位高度、拍摄侧别、视场角（见 `41`）。

### 【AI视频提示词】
按 `动作 → 表演 → 光影 → 运镜 → 风格` 组织：
- **动作**：可执行、有起止；明确手/眼/身体的具体运动；写“动作中途”的状态，不写完整过渡链（`31` 状态非过程）。
- **表演**：写可拍行为与表情变化的“过程”（“麻木→被点燃”“嗤笑→僵住”），配合呼吸、吞咽、抿唇、眼神动态；**不直接写情绪词**（`30`）。
- **光影**：光落在何处、何处留影、物体真实反光；不写易误导词（`50` 第 8 节）。
- **运镜**：与表头运镜一致，写明镜头如何随动作运动、在哪停。
- **风格**：首尾镜写风格标注（竖屏：“真人实拍，精品竖屏短剧，9:16”；横屏按项目替换，如“真人实拍，院线级电影感，21:9”）。

### 【负面限制】
- 视频模型支持负面时，按十类负面清单（人数/畸形/机位/表演/特效/空间/道具/血液/叙事/版权，见 `51`）逐镜挑相关项，不必每镜写全。
- 统一规避：正面证件照构图、张嘴说 VO、印记常亮、字幕水印、人物复制、多指畸形、眼部自发光。
- 图像模型（产资产阶段）**不支持负面**：改用正向描述，见 `10` 第 3 节。

### 台词列
- 无台词写 `—`。
- 有台词格式：`角色（表情/肢体｜发声·语速·停顿·重音）：英文台词`。
- 发声描写与表演系统的语言要求一致（音量反差、停顿即事件、口语瑕疵，见 `30` 第 5 节）。

## 3. 台词列的三种写法

1. 开口台词（配口型）：
   `马丁（举臂踏前、满脸激动｜音量拔高，尾音坚定）：I'm in! I'll follow you!`
2. 内心独白 VO（嘴唇不动）：
   `威廉（仰头凝望、嘴唇不动｜内心独白，声线压着震惊）：No ten-year-old talks like that.`
3. 画外音 OS（人物未必在画内）：
   `主播（电视画外音、语速快｜突发感）：Breaking news!`

## 4. 完整填写示例

### 示例 A · 眼神/反应特写

```text
镜53｜02:10.8-02:13.0｜惊恐眼神特写｜微推
【场景锚点】桌前·日晨，深色木墙与桌面，柔和暖光从落地窗斜入、低反差。
【视角锚点】摄影机贴近主体微侧的眼睛，背景与对谈者虚化。
【AI视频提示词】他睫毛轻颤、眼底从容荡然无存，只剩被戳破秘密的惊惧；缓缓吸一口气，像强迫自己镇定（反应在对方话音落下前已启动）。
【负面限制】禁正面眼部特写、眼部自发光或光束、眼球变色、眼泪流出、表情狰狞、第二人入镜。
—
```

### 示例 B · 双人关系（过肩 / 抓臂）

```text
镜32｜01:14.6-01:17.6｜双人抓手臂中景｜轻推后停
【场景锚点】桌旁·日晨，桌面与复古地毯，柔和暖光落在两人之间。
【视角锚点】摄影机位于两人侧方，朝抓臂急报者与皱眉主体拍摄。
【AI视频提示词】报信者冲上前、抓住对方空手的手臂，把消息砸出来；主体端杯的手稳稳不动、眉头蹙起却仍不当回事。
【负面限制】禁抓在端杯的手上、酒液洒出、手指多指、动作穿模、第三人入镜。
报信者（抓住手臂、身体前倾｜语速急快，消息咬重）：They took over the shipyard!
```

### 示例 C · 群像 / 集体反应

```text
镜12｜00:27.6-00:30.2｜众人齐声中全景｜随呐喊轻推
【场景锚点】厂区·日外，一群工装者面向高台、高举工具，日光铺满厂区。
【视角锚点】摄影机位于高台侧，能同时容纳主角与人群，朝呐喊者拍摄。
【AI视频提示词】众人涨红着脸、齐刷刷朝高台高举工具、放声应和（波浪式：先是一两人，再带动全场），声浪回荡；方才沉闷一扫而空。
【负面限制】禁声音稀落、表情木然、人物复制、夸张跪拜、所有人动作同步、镜头晃动。
众人（高举工具、面朝高台｜齐声呐喊，整齐有力）：We're in!
```

## 5. 中文工作稿 → 英文导演成品的映射

七段工作稿是“写什么”，英文成品是“怎么让模型稳定生成”，逐段映射（成品架构见 `40`）：

| 工作稿字段 | 英文成品段落 |
|---|---|
| 场景锚点 | 场景简述 + 场景空间地图 + 灯光锁定段 |
| 视角锚点 | 摄像机与构图 + 视场角（`41`） |
| 人物/参考图 | 有效参考（@标签 + 一句身份锚点，100% 匹配参考图） |
| （新增） | 首帧锁定 + 空间调度锁定（屏幕方位/距离/身体朝向/视线分开写） |
| AI视频提示词 | 动作时间轴（按 0:00–0:03 分块）+ 表演段（英文，源自表演档案） |
| （新增） | 物理特性锁定（重力/惯性/布料发丝延迟/液体，见 `42`） |
| 负面限制 | 行内局部锁定短句（不堆末尾大段负面，见 `43`/`51`） |
| 台词列 | 对白/音频规则（只念指定台词、前后留白、不说话嘴唇静止） |
| 运镜/景别 | 格式模式（单长镜头/受控多镜头）+ 摄像机运动 |

## 6. 高频错误与纠正

- 时间码重叠/断档 → 用上一镜结束时间作为下一镜起点；可用 `scripts/next_timecodes.py` 生成、`scripts/validate_storyboard.py` 校验。
- 提示词只写结果（“他很震惊”）→ 改写为过程与身体动作（“嗤笑僵住、端杯的手停在半空、呼吸慢半拍”）。
- 出现正面证件照构图 → 改为斜侧/过肩/微侧脸。
- VO 镜头让人物动嘴 → 明确“嘴唇完全闭合、不做口型”。
- 写了“眼睛发光/指节发白” → 删除，改用目光/视线/手指收紧等动作词，负面写“禁眼部自发光、异常高亮”。
- 道具状态前后矛盾（道具已归架却又从手里掉落）→ 统一道具时序：要么全程手持，要么归架后用其他道具承担失手重音，并在交付说明标注替换。
- 工作稿直接当中文喂给视频模型 → 先转英文导演成品，补齐首帧、空间距离、视场角、物理、灯光锁定。

# 21 · 拆镜规律（Shot Decomposition）

> 解决“剧本很短、镜头怎么铺开”。核心心法：**剧本给结果，分镜给过程。**

## 1. 结果转过程

剧本的动作行通常只交代结果，分镜要补足“准备—发生—反应”的可见过程。

- 剧本：`△女佣一脚踩空，从楼梯上滚下。`
- 分镜展开：
  1. 脚部特写：鞋悬在台阶边缘、脚踝失稳、鞋底打滑。
  2. 中全景：身体撞栏杆、连续滚下、发出惨叫。
  3. 群像：客厅众人闻声转头、茶面震出涟漪。
  4. 反打：高处主导者不动，形成控制关系。

把每个“结果动词”追问三问：**它发生前身体在做什么？发生时镜头在哪？谁看见了、如何反应？**

## 2. 一句 VO / 台词的多镜拆法

一句（段）内心独白常拆 3–4 镜：

1. 建空间：环境/方位镜头，交代人物所处。
2. 建关系：人物与他人/道具/空间的位置关系。
3. 关键动作：手、眼、身体的具体动作。
4. 伏笔/反应：一个暗示后续或情绪落点的镜头。

例：VO“我重生在一个十岁女孩身上” → ① 主观碎片坠入暗场（光色匹配）→ ② 中景后撤、身后虚影与孩子重合 → ③ 手部特写翻转稚嫩掌心确认 → ④ 近景抬眼、慌乱转为冷静。

## 3. 关键动作三镜法

重要、突发、带冲击的动作固定三镜：

- **预兆局部**：先拍将动的局部（门闩转动、袖中扣刀、鞋悬台阶、手指松开）。
- **执行全景**：动作在可看清空间关系的景别里发生。
- **反应群像**：受影响者/旁观者的集体反应（波浪式先后，见 `31` 群戏）。

适用：门被撞开、拔刀刺杀、滚落楼梯、杖/杆重击、球杆或酒杯脱手、众人举械、文件被推到对方面前。

## 4. 揭示顺序

默认按“**特写悬念 → 近景动作 → 全景空间 → 关系格局**”递进：

1. 先给一个引发疑问的特写（这是谁的手/什么东西/什么声音）。
2. 再给动作近景，让观众看清在发生什么。
3. 拉开成全景，交代空间与人物位置。
4. 落到关系构图，点明权力/情感格局（谁高谁低、谁被排斥、谁与谁结盟）。

## 5. 信息延迟揭示

- 关键人物/物体不要一开始就完整露出：先给手、脚、背影、影子、声音、局部反光。
- 让观众“先听到/先瞥见、后看清”，悬念与代入由此产生。
- 典型：刺客藏在袖中的刀（先见扣紧的手指，再见刀刃）；关键人物登场（先见伸入的手与门光）；听者反应（先挑眉，再走近）。

## 6. 对话场：把镜头给听者

- 对话不必“谁说话拍谁”。常把镜头对准**听者的反应**，说话人只留声音（与表演系统“聆听反应”互为表里，见 `30` 第 3 节）。
- 一句台词可拆成：说话人侧前近景 → 听者反应特写 → 关系中景。
- 这样在对话里同时推进“信息”与“关系变化”（轻敌者嗤笑时，反复切报信者愈发惨白的脸）。

## 7. 口述信息道具化

把抽象台词/背景信息绑定到一个**可拍道具**，让信息“被看见”：

- 命运/秩序 → 悬浮沙盘、星轨、图谱。
- 死亡结论 → 墙上与孩子头部同高的干涸血迹。
- 两条道路的抉择 → 桌上一左一右两份文件（冷暖光分别打）。
- 预言/外部事件应验 → 电视突发新闻（冷蓝事件光）。
- 谈判筹码 → 白板关键词、推过桌面的合同。
- 败露的恐惧 → 失手坠地的球杆/酒杯、洒开的液体。

道具的出现、移动、被触碰、坠落，都能成为镜头与转场的支点。道具状态必须前后时序一致（见 `22` 高频错误）。

## 8. 动作的连贯、方向与匹配

- 跨镜头保持动作方向一致（上一镜向右冲，下一镜承接向右），避免越轴造成空间混乱。
- 用“动作匹配”连接时空：被踩而蜷缩的手 → 现实中攥紧的同一只手。
- 用“遮挡”切换：裙摆、刀锋、杖、门板、木柱、血色充满画面后切入下一空间（详见 `24`）。
- 声音可先于画面：撞击声、画外台词先到，再甩/摇向声源。

## 9. 拆镜自检

- [ ] 每个结果动作都被展开成“准备—发生—反应”的可见过程。
- [ ] 关键动作具备“预兆局部 → 执行全景 → 反应群像”。
- [ ] 重要信息按“特写→近景→全景→关系”延迟揭示，未一次性全盘托出。
- [ ] 对话场至少有一处把镜头给听者反应。
- [ ] 抽象信息已绑定可拍道具，道具时序前后一致。
- [ ] 动作方向、光轴、视线跨镜头连续，无越轴。

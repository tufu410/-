## 1. 景别谱系

### 极近特写（Extreme Close-Up）
- 拍：眼瞳、血滴、印记、杖尖、刀柄、嘴唇局部。
- 用于：生死、爆点、超现实瞬间；全片少量、点到为止。
- 常用运镜：黑场前冲后骤停、固定等待爆点、极轻推。
- 禁忌：正面证件照式、眼球变色/爆裂、常亮特效。

### 眼神特写（Eye Close-Up）
- 拍：单/双眼微侧，眼神光与情绪（眼神动态强制项见 `31`）。
- 用于：觉醒、权力压制、决定形成、惊惧。
- 常用运镜：移焦、微推后冷停。
- 禁忌：眼部自发光、光束、浓妆、正对镜头。

### 手部特写（Hand Insert）
- 拍：架桥、握杆、攥拳、推文件、端杯、松开手指。
- 用于：紧张、伤害、试探、权力交接、心理外化。
- 常用运镜：移焦、顺手部下摇、固定等待。
- 禁忌：多指、畸形、首饰乱生、“指节发白”等颜色描绘。

### 道具特写（Prop Insert）
- 拍：门闩、酒杯、酒瓶、文件、球、白板、杖。
- 用于：预兆、转场开关、信息落锤。
- 常用运镜：固定、横移、上摇/下摇承接。
- 禁忌：可读乱码文字、商标、道具复制、自发光。

### 侧脸 / 侧前近景（Profile / Three-Quarter Close Shot）
- 情绪反应主力景别。
- 拍：微侧脸、近侧受光、远侧留影。
- 用于：开口台词、VO（嘴唇不动）、态度转变。
- 常用运镜：轻带、轻推、极慢靠近。
- 禁忌：正面怼脸、表情夸张、塑料皮肤。

### 中景 / 过肩中景（Medium / Over-the-Shoulder）
- 拍：人物上半身与互动；前景肩线遮挡。
- 用于：双人关系、对峙、抓臂、牵/挽、递物。
- 常用运镜：轻横移重组构图、过肩侧移揭示。
- 禁忌：人物穿模、关系轴线跳变、第三人乱入。

### 中全景 / 群像中景（Medium-Wide / Group）
- 拍：人物全身或多人布局、走位。
- 用于：格局、集体反应、权力场分布。
- 常用运镜：群像横移、随动作轻升/后撤。
- 禁忌：人物复制、所有人动作同步、集体夸张站起。

### 大全景 / 顶视（Wide / Top-Down）
- 拍：空间全貌、人与环境的体量反差、俯视布局。
- 用于：场景建立、超现实揭示、“两条路/多人围坐”布局。
- 常用运镜：顶视升起/下降、固定轻推。
- 禁忌：结构偏离参考图、过曝纯白、空间漂移。

### POV 主观镜头（Point of View）
- 拍：模拟人物视线，不出现本人身体。
- 用于：视线匹配、强制代入、随碎片/坠落的超现实体验。
- 常用运镜：顺目光横摇、高速坠落、环视。
- 禁忌：生成持有者身体、镜头旋转眩晕、穿越无关空间。

> 铁律：几乎不用正面脸部特写/正面近景；优先斜侧、过肩、微侧脸。

## 2. 运镜词汇表（运动 + 落点）

- 前冲/前推类：`快速前冲后骤停`、`轻推`、`极慢推近`、`短促前带后停`、`Dolly Zoom（极轻）`。
- 后撤类：`随起身轻微后撤`、`轻微后撤扩大距离`、`缓慢后撤`。
- 横移/横摇类：`轻横移`、`缓慢横移`、`顺视线横摇`、`甩镜后冷停`、`侧移揭示`。
- 环绕类：`低机位缓慢环绕四分之一圈`、`环绕半圈后冷停`。
- 升降类：`快速升起后停`、`轻微上升`、`顶视缓慢下降`、`顺动作上摇/下摇`。
- 跟拍类：`侧向跟拍后撞停`、`背侧稳定器跟随`、`顺脚步/手势短跟`。
- 焦点类：`微距移焦后冷停`、`由 A 移焦至 B`、`焦点越过前景落到后景`。
- 固定类：`固定等待`、`固定冷停`、`固定等待爆点`。

落点写法：`……后骤停 / 后冷停 / 后停`，并让落点与动作命中同步。

## 3. 机位与坐标用语词库

- 方位：左前方 / 右前方 / 侧前方 / 斜前方 / 正侧 / 背后侧 / 肩后。
- 高度：贴近地面低位 / 腰高 / 胸高 / 眼平 / 高位俯视 / 低位仰拍。
- 与人物关系：越过 A 肩侧 / 位于 A 与 B 之间 / 框在 A 掌心 / 以 A 肩线为前景。
- 空间锚点示例：床尾左前方、栏杆外侧、门板后侧、走廊侧墙、桌端部、落地窗侧、柜正前偏侧、灶台上方偏侧。
- 转英文成品时，把坐标写成可量化物理描述（`within 1 meter`、`back against the wall`、`camera at waist height on the subject's left-front`），见 `40` 空间调度。

## 4. 焦距、景深与画面层次

- 浅景深：特写/近景默认，背景虚化成柔光斑，突出主体。
- 长焦压缩：让远去者显得更远、强化孤立（父母走远、孩子留前景）。
- 前景遮挡 + 后景焦点：用肩、门板、柱、栏杆、椅背分层，制造“只给观众看到的真相”。
- 画面层次口诀：前景遮挡物 → 中景主体动作 → 后景空间/光源。
- 具体视场角度数（47/84/107/29/18/8°）、长焦/广角必写的可观测效果组合，见 `41-optics-camera.md`。

## 5. 如何为一个动作选景别

- 想制造悬念/爆点 → 极近特写或局部道具特写。
- 想表现情绪/态度 → 侧脸/侧前近景。
- 想交代两人关系/权力 → 过肩或双人中景，必要时横移重组。
- 想表现群体与格局 → 群像中景 / 中全景。
- 想交代环境与体量 → 大全景 / 顶视。
- 想让观众“成为”角色 → POV。
- 单一动作信息不足时，按“特写→近景→全景→关系”组合给出，而非反复用同一景别。

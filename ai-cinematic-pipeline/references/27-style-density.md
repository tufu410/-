# 27 · 题材决定密度与风格语法（Style & Density）

> 关键经验：**题材先决定镜头密度与语法**。同一套骨架，在冲突戏与温情戏里要切换不同“拍法”。

## 1. 核心：题材先决定镜头密度

- 冲突 / 爽点 / 刺杀 / 崩解 / 演讲：碎切、特写、强运镜、单镜偏短，节奏外显。
- 温情 / 生活 / 关系修复 / 日常喜剧：单镜 2.5–3.2 秒、双人同框关系构图、运镜克制、留白足。
- 一场戏内部也可切换：进入正题前用生活流（松弛），矛盾爆发时切悬疑/冲突语法（收紧），结束再回落。

## 2. 两种语法对照

| 维度 | 冷峻悬疑语法（冲突） | 生活流关系语法（温情） |
|---|---|---|
| 单镜时长 | 偏短（约 2 秒）、碎切 | 偏长（2.5–3.2 秒）、连贯 |
| 主力景别 | 极近特写、局部、反应 | 双人同框、中景、关系构图 |
| 运镜 | 前冲、环绕、甩镜、Dolly Zoom | 轻移、顺势跟、固定等待 |
| 信息揭示 | 延迟、强符号、悬念 | 随动作自然带出 |
| 心理表现 | 眼神、阴影、道具特写 | 习惯动作、两人互动 |
| 光 | 强对比、事件光 | 柔和、低反差、晨光 |

不要把刺杀戏的冷峻碎切硬套到日常关系戏：会用力过猛、人物失真。

## 3. 心理外化：先找可拍的身体动作

心理活动不直接“说结果”，而找一个可拍的习惯动作（与表演系统的手头事务、小动作触发条件一致，见 `30`/`31`）：

- 旧瘾复发：手摸向放酒/烟的位置、扑空、停顿。
- 强装镇定：捏袖口、肩膀内收、吞咽。
- 试探对方：先垂眼、再抬眼观察反应。
- 情绪收放：眼泪聚起又迅速收住（克制，不嚎哭）。
- 专注思考：无意识转笔、笔尖在资料下划线。

## 4. 双人戏：移焦与同框

- 温情戏少用单人正反打，多用**双人同框**让两人在一个画面里发生关系。
- 注意力/权力交接用**移焦**完成（前景失焦、后景清晰），比硬切柔和。
- 两人视线汇聚到同一信息点（同看一份文件、同一个锅、同一处白板），关系自然贴近。

## 5. 前景遮挡：只给观众看的真相

- 用一方肩背做前景，揭示另一方“不希望被对方看到”的表情：
  - 主角在对方转开视线后，眼泪收住、露出狡黠的笑。
  - 表面乖巧的角色背对众人时翻白眼、再瞬间恢复乖巧。
- 镜头移到“当事人看不到、观众看得到”的角度，制造信息差与代入。

## 6. 运镜顺势、与动作同步停

- 镜头跟随已有动作（翻页、转身、推轮椅、抬手）顺势运动，不额外制造无来由的运动。
- 动作完成/命中时镜头同步停住，形成自然重音。
- 生活戏运镜幅度小、速度缓；冲突戏才用快速、大幅度运动。

## 7. 情绪距离绑定方向

- 靠近 / 承诺 / 亲密：前推、跟拍、并入同一光区、缩短物理距离。
- 疏远 / 排斥 / 压迫：后撤、拉开距离、分处冷暖两区。
- 用摄影机“靠近还是退后”直接表达关系，无需台词解释（人际距离学见 `30` 第 4.3 节）。

## 8. 光线随空间功能

- 生活区（卧室、餐桌、厨房）：东向暖晨光，柔和、有情。
- 工作区（书房、谈判桌）：北向中性日光、台灯局部光，清晰、有理。
- 从生活进入工作，光由暖转中性；同一人物在不同光区呈现不同状态（光区叙事见 `50`）。

## 9. 固定等待，让结果自己发生

- 喜剧/冲击来自“固定镜头冷静旁观”：让焦蛋冒烟、让动作失误自然发生，镜头不追不抢。
- 比起快速切一堆反应，一个稳定等待结果的镜头更松弛、更有生活质感。

## 10. 表演与口型规则

- 开口台词：嘴部自然配口型，表情与台词情绪一致，动作克制真实。
- VO / OS / 内心独白：嘴唇完全闭合、不做任何口型；可配眼神、呼吸、身体动作。
- 闪回画面人物不随现实 VO 开口。
- 儿童角色承载成熟心智时，以幼态外形承载成熟判断，靠眼神与节奏而非浓妆、夸张表情，避免“成人化表演”长在儿童脸上。
- 不磨皮、不塑料皮肤、不 AI 失真；保留真实皮肤质感。

## 11. 标志性符号与钩子的浓度调节

- 项目标志性符号（印记/图腾/超自然元素/特定配色）是记忆点，冲突/觉醒/集尾保留并适度强化。
- 温情/生活戏降低符号浓度：符号可不出现或仅一闪，光效收敛，避免日常场景被特效打断。
- 强钩子（集首局部动作、集尾悬念）始终保留，但温情集钩子可落在情感悬念而非特效。

## 12. 自检

- [ ] 已按题材确定镜头密度（冲突碎切 / 温情长镜同框）。
- [ ] 未把冷峻悬疑语法硬套到生活戏。
- [ ] 心理活动已外化为可拍身体动作，未只写“他很……”。
- [ ] 双人戏多用同框与移焦；前景遮挡用于“只给观众看的真相”。
- [ ] 运镜顺势、与动作同步停；情绪距离与镜头方向一致。
- [ ] 光线随空间功能；固定等待处镜头松弛。
- [ ] VO 嘴唇不动、开口台词配口型；无磨皮、无儿童成人化失真。
- [ ] 标志性符号与钩子浓度与题材匹配。

# 25 · 节奏与钩子（Rhythm & Hooks）

> 决定一集“好不好看、停不停得下来”。节奏来自长短镜搭配与动静对比，钩子负责留住观众进入下一集。

## 1. 单镜时长基准

- 极近特写 / 眼神 / 反应：约 2.0–2.4 秒。
- 手部 / 道具特写：约 2.0–2.6 秒。
- 侧脸 / 侧前近景（台词）：约 2.4–3.0 秒。
- 中景 / 过肩：约 2.6–3.0 秒。
- 中全景 / 群像 / 大全景：约 2.6–3.2 秒。
- 温情/生活戏整体取上限（2.5–3.2 秒、少切换）；冲突/爽点戏可压到约 2 秒、加快剪辑。

时长为台词服务：一句台词所需的自然语速 + 动作起止决定该镜下限，不为凑数硬拖，也不让动作没做完就切。横屏电影可整体放宽节奏、允许更长的调度长镜。

## 2. 节奏公式

固定可复用的五拍：

1. **蓄力（固定等待）**：安静/局部预兆，制造期待。
2. **突发**：动作爆发（拔刀、踩空、推门、坠物、举械）。
3. **骤停**：动作命中/完成瞬间镜头停住，形成重音。
4. **扫描**：横移/移焦扫过相关者反应。
5. **冷停**：落在主角或关键人物稳定、克制的画面上。

例：有人滚楼梯 = 脚部打滑（蓄力）→ 滚下（突发）→ 撞转角（骤停）→ 众人转头（扫描）→ 主导者居高定格（冷停）。

## 3. 集首钩子

- 紧接上集结尾，用一个**局部动作特写**开场（脚步、手、眼神、道具），快速把观众拉回。
- 集首避免一上来就大全景平铺直叙；先给动作与悬念，再建立空间。

## 4. 集尾强钩子

标准构成（可按题材增减）：

- 主角居于构图中心或高处，身体稳定不动。
- 低机位仰拍 / 极慢推近，强化气场。
- 项目标志性符号（印记/图腾/超自然元素，若有）极短一闪、随即收敛，不持续发光。
- 最后一句台词/数字低沉落定，光效随之收敛。
- 定格在冰冷、笃定或惊惧的凝视上；明文标注“集尾钩子”。

钩子的本质：抛出一个未解决的强悬念（预言数字、身份恢复、即将到来的对峙、败露的危机）。温情集的钩子可落在情感悬念而非特效。

## 5. 一场戏的情绪曲线

- 每场设定情绪“起点 → 上升 → 顶点 → 落点”，镜头密度配合：
  - 起点（铺垫）：较长镜、稳定、留白。
  - 上升（信息/冲突累积）：剪辑渐快、反应特写增多。
  - 顶点（爆点）：突发动作 + 骤停。
  - 落点（冷停/钩子）：克制的定格。
- 例：报信戏 = 轻敌者从容做私人动作（低）→ 报信、嗤笑（累积）→ 真相败露（顶点，失手坠物）→ 咬牙决断赴现场（冷停钩子）。

## 6. 长短镜搭配与留白

- 连续短切之后给一个稳定长镜，让观众喘息、让信息沉淀。
- 关键反应留半拍“不动”，情绪比塞满动作更有力（停顿即事件，见 `30` 第 5 节）。
- 温情戏让动作在双人同框里自然发生，不打断；喜剧/冲击来自冷静旁观的固定镜头。

## 7. 节奏自检

- [ ] 单镜时长与台词/动作匹配，无硬拖、无半途切。
- [ ] 关键动作符合“蓄力→突发→骤停→扫描→冷停”。
- [ ] 集首以局部动作钩子承接上集；集尾有明确未解决悬念并标注。
- [ ] 情绪曲线清晰，镜头密度随起伏变化。
- [ ] 长短镜搭配，有留白与冷停，未全程一种节奏。

# 53 · 全流程交付前总质检（Final QC）

> 交付任何产物前的最后一道闸。各子系统有自己的细清单，本文件负责跨阶段一致性与“一键过闸”。发现问题就改，改后重算受影响镜头的时间码与连续性。

## 目录

1. 跨阶段一致性（最容易出问题，优先查）
2. A 图像资产质检
3. C 分镜工作稿质检
4. D 表演层质检
5. E 英文导演成品质检
6. 交付说明必须写清的事
7. 30 秒过闸速查

---

## 1. 跨阶段一致性（优先查）

- [ ] **资产 ↔ 分镜**：分镜里出现的每个角色/场景/道具，都有对应参考资产或明确文字锚点；资产的服装、配饰、空间结构、地标与分镜描述一致。
- [ ] **分镜 ↔ 导演成品**：每个镜号的景别、动作、台词、人物数量、道具、光源在中文工作稿与英文成品之间一一对应，无遗漏、无凭空新增。
- [ ] **表演档案 ↔ 单镜**：各镜表演段与总档案的核心特质、声线、标志小动作、眼神逻辑一致；声线文本逐字复制、未随场景改写。
- [ ] **形象连续**：跨镜/跨集的年龄、体型、发型、服装、伤痕、血迹、干湿/整洁状态连续；被摧残者状态累积、不重置。
- [ ] **道具时序**：身份道具不丢失、不错配；失手/坠落道具在当时确实在角色手中；归架后不再出现于手里。
- [ ] **空间与光轴**：同一场戏跨镜光源方向、屏幕朝向、人物左右关系、地标距离一致（刻意反打除外，且已注明）。
- [ ] **色彩身份**：特殊色/血液/标志物按项目色彩身份表用色，未越界（`50`）。
- [ ] **台词**：英文台词与剧本逐句对应、未擅改；VO/OS 嘴唇规则正确；无额外即兴台词。

## 2. A 图像资产质检（清单见 `10` 第 7 节）

- [ ] 模型路由正确（人物 Soul 2.0/AI Cast；场景 Soul Cinema；道具 NBP/GPT Image；编辑 NBP 优先；纹理才用 Seedream；反打 GPT Image）。
- [ ] 正文无画幅/分辨率参数标记；无品牌、IP、真人名；无 `painterly`/`character reference sheet` 误触发。
- [ ] 人物用 Soul ID + 文字身份锚点；编辑最小 CHANGE、详尽 PRESERVE，移除处写明填充内容。
- [ ] 光照/材质具体、色调 60/30/10 取自用户、提示词精炼不臃肿。

## 3. C 分镜工作稿质检（清单见 `20` 阶段 G）

- [ ] 镜号连续无重复跳号；时间码无缝咬合（用 `scripts/validate_storyboard.py` 校验）。
- [ ] 每镜七段齐全；首尾镜风格标注与画幅匹配。
- [ ] 几乎无正面脸部特写；以斜侧/过肩/微侧脸为主。
- [ ] 关键动作有“预兆→执行→反应”；信息延迟揭示；对话场有给听者的镜头。
- [ ] 题材密度正确（冲突碎切 / 温情长镜同框）；集首集尾钩子到位。
- [ ] 纯文本分行、非表格。

## 4. D 表演层质检（清单见 `32`）

- [ ] 每个角色有指向对手的动词式行动目标、阻碍与利害代价。
- [ ] 每场 2–4 次节拍切换且肉眼可见；反应早于对手台词结束；有消化时刻。
- [ ] 有手头事务与“动作中断”重音；距离变化有动机；地位靠肢体。
- [ ] 小动作都带触发条件；有伪装面具与 `However, when X…` 破碎句。
- [ ] 眼神动态完整（眼跳、眨眼、高光、眼先于头、随节拍变化）。
- [ ] 写状态不写过渡过程；表演段不含服装/机位/调色；主角镜自评 ≥4 级。

## 5. E 英文导演成品质检（19 项见 `43` 第 7 节）

- [ ] 只含本镜可见可闻元素；无失效 @标签、场景编号、表头、“承接上文”等泄露。
- [ ] 首帧即带主体、无空开篇；每个人物位置、视线、身体朝向、地标距离锚定、机位侧别明确。
- [ ] 视场角匹配内容、做了防漂移；空间规则在风格前、光学在美学前、灯光是锁定项。
- [ ] 物理（重力/惯性/布料发丝延迟/液体）、灯光（主光/方向/曝光优先级/无平光）齐备。
- [ ] 动作时间块逻辑自洽、时长内物理可行；对白干净、前后留白、嘴唇规则正确。
- [ ] 无重复/多余人物、无道具错手、无漂浮运动；行内局部锁定取代大段负面。
- [ ] 成品为简洁英文；只输出提示词本身，不带质检/推理。

## 6. 交付说明必须写清的事

- 场景数、镜头总数、总时长、整体光线与色调处理（开场一两句）。
- 所有为遵循约束而做的**替换/改动**：原方案是什么、改成了什么、为什么、是否存在互斥取舍（道具替换、动作调整、情节增删、配色调整等）。
- 需要用户去 UI 设置的参数（画幅、分辨率、Soul ID、模型、时长、帧率）。
- 未能完成的部分、原因与所需补充输入；不静默替换、不擅自降级。

## 7. 30 秒过闸速查（最关键 12 条）

1. 只写本镜元素，无上下文泄露、无失效标签。
2. 人物首帧即出现、位置/视线/朝向/距离准确。
3. 无正面证件照构图；VO 嘴唇不动、开口台词才动嘴。
4. 表演写行为不写情绪，有目标、节拍、反应、眼神。
5. 主角表演 ≥4 级；群像波浪式不同步。
6. 每镜光源方向明确、跨镜连续、无扁平平光。
7. 无“眼睛发光/指节发白”等误导词，负面用安全表述。
8. 道具在正确的手、时序自洽、无复制。
9. 视场角匹配内容且锁定不漂移；运动符合物理。
10. 台词为英文原句、无额外台词、时间轴干净。
11. 资产/分镜/表演/成品四者形象与状态连续。
12. 英文成品只给提示词；中文分镜纯文本分行、非表格。

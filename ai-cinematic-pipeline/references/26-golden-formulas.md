# 26 · 黄金镜头公式（Golden Shot Formulas）

> 把反复出现的戏剧场景固化成镜头序列模板，遇到同类情节直接套用，再按具体台词、道具与项目配色替换内容。序列是结构参考不是教条，需结合 `21` 拆镜规律与 `27` 题材密度增减。

## 目录

1. 觉醒 / 重生 / 身份揭示
2. 刺杀 / 背叛
3. 超自然崩解 / 消散（特效配色按项目色彩身份替换）
4. 权力逆转
5. 预言 / 信息应验
6. 演讲动员 / 群像效忠
7. 商业谈判（傲慢 → 平等）
8. 慌张报信 → 轻敌 → 震惊 → 败露恐惧

---

## 1. 觉醒 / 重生 / 身份揭示

1. 黑场前冲极近特写（关键标志物/血液悬停→倒流，匹配成新身体上的真实痕迹）。
2. 眼神特写移焦：睫毛细物→瞳孔，骤然睁眼、先失焦后收紧、猛吸半拍。
3. 侧前近景随起身后撤：撑起上身、确认身体/伤口、扫视环境；标志性符号一闪即灭。
4. 手部特写：陌生的手压床、痕迹滴落手背，用遮挡转场。

要点：VO 嘴唇不动；先制造“为什么是这具身体/这个处境”的疑问。无超自然设定时，去掉标志物、保留“睁眼→确认身体→扫视环境”的觉醒骨架。

## 2. 刺杀 / 背叛

1. 大全景顶视升起：建立空间，主角居中、背叛者跪/立于侧后。
2. 中全景低机位环绕：主角从容掌控（做日常/仪式动作）。
3. 手部移焦：主角放松的手 → 背叛者袖中扣紧武器的手。
4. 道具特写上摇：武器抽出（火焰/反光）。
5. 中全景侧向跟拍后骤停：背叛者暴起、武器命中、主角微笑凝固。
6. 侧脸近景极轻 Dolly Zoom：主角瞳孔中世界破碎、笑意消失。
7. 过肩侧移揭示背叛者：贪欲表情、下半脸被事件光照亮。

要点：背叛者完整台词安排在命中后；不提前防御、不反复刺击；威胁平淡、暴力无预兆地到来（`30`/`32`）。

## 3. 超自然崩解 / 消散

> 适用于神体崩解、化尘、消散、能量解体等。粒子配色严格按项目色彩身份制（`50`）：示例项目用银蓝；写实项目可改为尘灰、火星、碎片等真实材质。

1. 眼瞳极近特写固定：虹膜/皮肤边缘开始化为指定微粒。
2. 中全景环绕半圈：身体从胸口向全身化作碎片、向上卷起；背叛者退步又贪婪抓取。
3. POV 随碎片高速坠落：掠过空间、被光吞没。
4. 光色匹配转场：碎片收缩成标志物，抵达新身体床侧骤停。
5. 中景后撤：身后虚影与新身体短暂重合后淡去。

要点：特效色专属、不挪用给凡人/普通物体；粒子不遮满全屏、不血腥肢解；标志物一闪即灭、不持续发光。

## 4. 权力逆转

1. 低位仰拍强者（高台/主位/楼梯高处）居中构图。
2. 眼神特写冷停：目光锁定、下颌绷紧。
3. 反打反应者：手停半空、吞咽、退步（轻微后撤）。
4. 走位换阵营：主角从弱势光区进入权力光区中心，或众人被迫让出空间。
5. 道具落锤：杖/杆重击、文件推到中央、合同落桌。

要点：用高度差与光区变化表现逆转（地位崩塌反转见 `30` 第 4.4 节），不靠台词宣告。

## 5. 预言 / 信息应验

1. 画外爆出数字/断言（先闻其声，说话者暂不露）。
2. 甩镜锁定预言者并冷停。
3. 视线匹配横摇：摇向电视/文件/事件现场。
4. 群像横移反应：怀疑→僵住→转愤怒或惊惧（波浪式不同步）。
5. 道具特写落锤：新闻最终数字、文件被光照亮、戒指/手失力。
6. 上摇：全场目光从事件物转向预言者。
7. 预言者近景定格：不炫耀、像陈述已知事实。

要点：新闻用“某台风格”，避免真实台标精确复制；屏幕光只局部染色（`51` 版权类）。

## 6. 演讲动员 / 群像效忠

1. 大全景建立：粗粝空间（厂区/营地/会场）与聚集人群。
2. 群像中景横移：人群疲惫、疑虑、沉默。
3. 主角居高（高台/箱体）低机位仰拍：体量反差。
4. 近景轻推：先激将。
5. 中近景顺手势：再给希望。
6. 群像沉默：低头、交换眼神、无人先动。
7. 关键者（头领）近景：被点燃、握拳、肌肉绷紧。
8. 头领中景前带：第一个表态大喊。
9. 群像快速横移轻升：众人举起工具/武器。
10. 中全景随呐喊轻推：齐声效忠。
11. 主角侧脸特写：微扬下巴、笃定，转场。

要点：人群反应有“沉默—带头—跟从”的层次，不一开始就整齐激昂（群戏波浪式，见 `31`）。

## 7. 商业谈判（傲慢 → 平等）

1. 入场：弱势方（轮椅/低位/少数派）进入，众人探究、轻视。
2. 强势方站立俯视、挑眉、轻慢发问；弱势方坐姿/低位。
3. 一个仪式动作（碰杯/递烟/让座）：弱势方先征询同伴再回应。
4. 弱势方抛出对方没料到的关键信息（地块/数据/筹码）。
5. 同伴补刀后把功劳推回弱势方。
6. 强势方态度转变：由站立改为坐下/凑近，高差拉平 = 开始平等。
7. 弱势方逐条列筹码（可掰手指/点文件）。
8. 文件推过桌面：合作落点。

要点：用“站→坐、俯视→平视”的高差变化外化态度；信息靠数据与道具支撑；距离博弈见 `30` 第 4.3 节。

## 8. 慌张报信 → 轻敌 → 震惊 → 败露恐惧

1. 轻敌者正悠闲做私人动作（俯身击球/调酒/擦拭）。
2. 门猛推开，报信者冲入（声音先行）。
3. 报信者急喊；轻敌者手一抖、动作失误（杆滑球偏）。
4. 轻敌者直身、皱眉、数落对方毛躁（从容）。
5. 报信者抓住对方手臂报出第一个消息。
6. 轻敌者甩开、嗤笑、端杯（把事情说成“烂摊子、看戏就好”）。
7. 报信者反驳“对方已搞定关键人群”。
8. 轻敌者嗤笑僵住、皱眉否定（搬出旧例）。
9. 报信者惨白、复述亲眼所见（异常已发生）。
10. 轻敌者失声“你说什么”。
11. 报信者揭开共同秘密（假账/亏空/审计）。
12. 轻敌者反应特写：瞳孔收紧、呼吸慢半拍。
13. 失手重音：手中道具（按道具时序选）脱手坠地。
14. 双人僵住全景：落地道具、洒开的液体、沉默。
15. 轻敌者惊惧眼神 → 咬牙切齿（“他不可能做到”）。
16. 转身决断、招呼同伴赶往事发现场（冷停钩子）。

要点：道具时序必须自洽——若道具早已归架，则用仍在手中的其他道具承担失手重音，并标注替换；情绪靠身体动作层层递进（克制→崩溃的情绪阶梯，见 `32`），不靠一句“他很害怕”。
